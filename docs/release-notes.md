An animated pixel-art wallpaper for macOS: Claude jumps out of a helicopter over a city at sunset.

**Install** (Terminal, no sudo):

```bash
curl -fsSL https://raw.githubusercontent.com/B0yko/claude-parachute-wallpaper/main/install.sh | bash
```

The installer downloads `Claude-Parachute-*.zip` below, checks its SHA-256 and runs the app's self-test before
installing. Uninstall with `... | bash -s -- uninstall`, which also restores your previous wallpaper.

- 60 s seamless loop, 24 fps, pixel-exact on a 16" MacBook Pro, crisp on any screen
- Animates only while the desktop is in front; 0% CPU while you work in an app, asleep, locked or in Low Power Mode
- Universal app (Apple Silicon and Intel), macOS 13+, no permissions, no network after install
